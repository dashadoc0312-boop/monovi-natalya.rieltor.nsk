# Сайт-визитка эксперта по недвижимости

Одностраничный сайт для ссылки из профиля Instagram. Цель — заявки на консультацию.

**Стек:** Next.js (App Router) + React + TypeScript + Tailwind CSS. Никаких тяжёлых библиотек: анимации на CSS, иконки — встроенные SVG.

---

## 1. Что где лежит

```
src/
  config/site.config.ts   ← ВСЕ данные специалиста: имя, текст «обо мне», услуги, контакты, SEO
  i18n/ru.ts              ← тексты кнопок, формы, сообщений об ошибках
  app/
    page.tsx              ← порядок блоков на странице
    layout.tsx            ← шрифты, title, description, Open Graph
    globals.css           ← цвета и шрифты (дизайн-токены)
    icon.svg              ← иконка сайта (favicon)
    opengraph-image.tsx   ← картинка-превью ссылки, собирается из конфига
    api/lead/route.ts     ← приём заявок → Telegram-бот
  components/             ← блоки страницы (Hero, About, Services, Consultation, Contacts…)
public/images/            ← сюда кладётся фото
```

Структура страницы: первый экран → обо мне → чем могу помочь → заявка на консультацию → контакты → футер.
На смартфоне снизу появляется компактная кнопка «Записаться на консультацию», когда кнопки первого экрана ушли из виду; у формы она прячется.

## 2. Запуск на своём компьютере

Нужен Node.js 20.9 или новее (https://nodejs.org, версия LTS).

```bash
npm install
cp .env.example .env.local     # и заполните переменные (см. раздел 4)
npm run dev
```

Откройте http://localhost:3000. Изменения в файлах видны сразу.

Проверка перед публикацией:

```bash
npm run build && npm start
```

## 3. Что нужно заполнить, чтобы сайт был готов

Все пункты — в `src/config/site.config.ts`. Незаполненные места на сайте подсвечены бежевым фоном с пунктиром: пока такая подсветка видна, что-то ещё не заменено.

| Что | Где в конфиге | Примечание |
|---|---|---|
| Имя и фамилия | `person.firstName`, `person.lastName` | |
| Роль и название агентства | `person.role` | |
| Фото | `portrait.src` | Положите файл в `public/images/portrait.jpg`, укажите `"/images/portrait.jpg"`. Вертикальное, 4:5, от 1200 px по высоте. Сайт сам сожмёт его в WebP/AVIF. |
| Краткая биография | `about.bio` | 2–3 коротких абзаца |
| Опыт, специализация, география | `about.facts` | Только реальные данные; ненужный пункт удалите |
| Принципы работы | `about.principles` | Сейчас стоят черновые формулировки — проверьте, что они правда про неё |
| Услуги | `services` | 3–4 пункта; иконки: `key`, `sale`, `growth`, `shield` |
| Телефон | `contacts.phone`, `contacts.phoneDisplay` | `phone` — `+79991234567`, `phoneDisplay` — как показывать |
| Telegram | `contacts.telegram` | имя пользователя без `@` |
| WhatsApp | `contacts.whatsapp` | номер без `+`: `79991234567`; пустая строка `""` скрывает пункт |
| Instagram | `contacts.instagram` | имя аккаунта без `@` |
| Почта | `contacts.email` | необязательно, `""` — скрыть |
| Заголовок и описание для поиска и превью | `seo.title`, `seo.description` | |

Цвета и шрифты меняются в `src/app/globals.css` (блок `@theme`) и `src/app/layout.tsx`.

## 4. Как приходят заявки

Форма **реально отправляет данные** — режим задаётся в `leadDelivery` в конфиге.

### Режим `"api"` (по умолчанию, рекомендую): заявки приходят в Telegram от бота

Заявка уходит на сервер сайта, а он пересылает её сообщением в Telegram. Бесплатно, уведомление приходит мгновенно.

1. В Telegram откройте **@BotFather** → `/newbot` → придумайте имя. Он выдаст **токен** вида `123456:ABC-...`.
2. Найдите своего бота по имени и нажмите **Start** (без этого бот не сможет вам писать).
3. Узнайте свой **chat id**: откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` — в ответе найдите `"chat":{"id":123456789`. Это число и есть ID.
   *Для группы:* добавьте бота в группу, напишите в ней любое сообщение и откройте ту же ссылку — ID группы начинается с минуса.
4. Добавьте переменные `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в `.env.local` (локально) и в настройки хостинга (см. раздел 5).

Если переменные не заданы или Telegram недоступен, посетитель не теряет заявку: он видит сообщение об ошибке и кнопки «Отправить в WhatsApp» / «Отправить в Telegram» с уже готовым текстом.

От спама: скрытое поле-ловушка для ботов и проверка полей на сервере.

### Режим `"whatsapp"`: без сервера
Кнопка «Отправить заявку» открывает WhatsApp с готовым сообщением на номер из `contacts.whatsapp`. Посетителю остаётся нажать «Отправить».

### Режим `"telegram"`: без сервера
Текст заявки копируется в буфер обмена, и открывается чат с `contacts.telegram`. Посетителю нужно вставить текст и отправить. (Telegram не позволяет подставить текст в личный чат автоматически, поэтому WhatsApp-вариант удобнее.)

Состояния формы: проверка полей с подсказками, «Отправляем…» с индикатором, «Заявка отправлена», ошибка с повтором и запасными кнопками.

## 5. Публикация и постоянная ссылка для Instagram

Проще всего — **Vercel** (бесплатный тариф подходит, Next.js — их фреймворк).

1. Загрузите проект в репозиторий на GitHub (github.com → New repository → загрузите файлы, кроме `node_modules` и `.env.local`).
2. Зайдите на https://vercel.com через аккаунт GitHub → **Add New → Project** → выберите репозиторий → **Deploy**.
3. В проекте: **Settings → Environment Variables** — добавьте `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` и `NEXT_PUBLIC_SITE_URL` (адрес сайта, например `https://imya-familiya.vercel.app`). Затем **Deployments → Redeploy**, чтобы переменные подхватились.
4. Вы получите постоянный адрес вида `https://<название>.vercel.app`. Его можно сделать короче в **Settings → Domains** (сменить поддомен `.vercel.app` или подключить свой домен, например `imya-realty.ru`).
5. Instagram → **Редактировать профиль → Ссылки → Добавить внешнюю ссылку** → вставьте адрес.

Дальше любое изменение в репозитории автоматически публикуется за минуту.

После публикации отправьте ссылку себе в Telegram — должно появиться превью с именем и заголовком. Отправьте тестовую заявку с телефона и убедитесь, что бот её прислал.

Альтернативы: Netlify, Cloudflare Pages, Render — тоже работают с Next.js.

## 6. Смена языка

Тексты интерфейса — в `src/i18n/ru.ts`. Для другого языка скопируйте файл (например, в `en.ts`), переведите значения, подключите его в `src/i18n/index.ts` и поменяйте `locale` в конфиге. Тексты о специалисте переводятся прямо в `site.config.ts`.

---

## 7. Проверено

- Ширина 360, 390 и 1280–1440 px: нет горизонтальной прокрутки, главная кнопка видна на первом экране смартфона.
- Все ссылки: `tel:`, `t.me`, `wa.me`, Instagram; внешние открываются в новой вкладке.
- Форма: ошибки полей и фокус на первом неверном поле, загрузка, успех, ошибка сервера/Telegram с запасными кнопками; HTML-символы в комментарии экранируются; ловушка для ботов.
- Фиксированная кнопка на смартфоне появляется и прячется в нужный момент.
- Доступность: семантические секции и заголовки, подписи полей, видимый фокус, контраст текста не ниже 4.5:1, уважение к настройке «уменьшить движение».
